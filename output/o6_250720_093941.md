# 🏷️ Titre synthétique
Refactorisation de la fonction `send_shiva_notif` pour grouper les notifications par domaine

# 🧾 Résumé technique
- La fonction `send_shiva_notif` a été refactorisée pour grouper les destinataires par domaine avant d'envoyer les notifications.
- Les destinataires sont maintenant triés et envoyés en lots par domaine, ce qui permet de mieux gérer les notifications pour chaque domaine spécifique.
- Les tests unitaires ont été mis à jour pour couvrir les nouvelles fonctionnalités et les cas de test supplémentaires.
